# 7 шаг. Экран 5 Report ( Отчеты)

### **“Как показать всю картину кратко, чисто и понятно?”**

**Это готовая короткая выжимка по портфелю, которую удобно посмотреть, показать или сохранить.
Это экран не для глубокого анализа. 
Это экран для сводки.** 

Когда человек открывает `Report`, он должен получить:

- Краткую картину портфеля
- Изменение за период
- Лучшие и худшие позиции
- Структуру по категориям
- Общий комментарий
- Следующий фокус внимания

## 1.  Portfolio Snapshot (Снимок портфеля)

Короткий верхний блок:

- **Total Value (Общая стоимость)**
- **Total PnL (Общий результат)**
- **Stable Reserve (Резерв  стейблов)**
- **Positions Count (Число позиций)**

## 2. Change for Period (Изменение за период)

Нужен блок, который показывает движение не “вообще”, а за выбранный период.

- **Change 7D (изменение за 7 дней)**
- **Change 30D (изменение за 30 дней)**

## 3. Best / Worst Positions (Лучшие / Худшие позиции)

- Лучшая позиция
- Худшая позиция
- Biggest position (Самая большая позиция)

## 4. Allocation Summary (Сводка структуры)

Короткая структура по категориям в виде маленькой диаграммы :

- Crypto (Крипта)
- Stocks (Акции)
- Metals (Драгметаллы)
- Cash / Stables (Кэш / Стейблы)

## 5. Main Notes (Главные заметки)

Очень короткий текстовый блок.

Туда выводится:

- Что важно сейчас?
- Что изменилось?
- На что смотреть дальше?

## 6. Focus / Next Step (Фокус / Следующий шаг)

Отдельный короткий блок:

- Держать текущую структуру
- Следить за ключевыми уровнями по ETH
- Не увеличивать риск
- Готовить резерв к добору
- Пересмотреть долю актива X

## 3. Анти-паттерны — НЕ ДЕЛАТЬ

1. ❌ **Не возвращать shared-secret guard в Apps Script.** Авторизацию уже держит один слой —
   Vercel serverless proxy (`api/_investorProxy.js`) на Supabase-токене + email владельца.
   Guard дал ноль безопасности и стоил ~2 дней простоя main-аккаунта.
2. ❌ **`git revert` ≠ деплой.** Для `.gs` откат кода без `clasp push` + передеплоя оставляет
   сломанный деплой. Web-app `/exec` версионного деплоя не обновляется от push в HEAD.
3. ❌ **Не «хардить» без модели угроз.** Security ради security ломает рабочее.
4. ❌ **Не вести параллельные ветки на одну тему.** Одна тема — один владелец.
5. ❌ **Не менять Apps Script deployment URL.** Передеплой — только тем же deployment ID.
6. ❌ **Не держать `.gs` незакоммиченными** — `clasp pull` / параллельный агент их затирают.
7. ❌ **`setFormula` только с `;`-разделителями.** Таблица в русской локали: `,` — десятичный
   разделитель, формулы с запятыми дают `#ERROR!` (IFERROR не спасает). Инцидент 2026-07-16:
   каскад #ERROR! по Обзору/Риску. Образец правильных формул — `IC_HL_refreshPortfolioAccounting_`.
8. ❌ **Не вставлять строки в «Расчеты» через `insertRow`** — правее колонки K живут служебные
   блоки (L–O агрегаты, W–X фьючерсный учёт), вставка их сдвигает и ломает. Копировать
   строки-шаблоны — только A..K, не `getLastColumn()`.

# 3 шаг. Экран 1 Overview (Обзор)

### **“Что с моим портфелем прямо сейчас?”**

Этот экран не должен быть перегружен.
Он для быстрого понимания общей картины.
Он не для глубокого копания.
Минимум шума.
Максимум смысла.

После открытия `Overview - обзор` человек должен сразу понимать:

- Сколько стоит сейчас весь портфель?
- Сколько было всего вложено?
- Он в плюсе или в минусе?
- Как распределён капитал?
- Какие активы самые большие?
- Где риск / перекос / концентрация?
- Что важно сейчас?

# Структура экрана

### Блок 1. Верхняя линия метрик

1. **Total Portfolio Value** - общая стоимость портфеля
2. **Total Invested** - всего вложено
3. **PnL $** - прибыль/убыток в деньгах
4. **PnL %** - прибыль/убыток в процентах
5. **Stable Reserve** - резерв в стейблах / кэше
6. **Positions Count** - количество активных позиций

### Блок 2. Визуальная структура

1. **Allocation by Asset** - Диаграмма распределения по активам
    - BTC
    - ETH
    - TON
    - Tesla
    - Microsoft
    - Gold
    - Silver
2. **Allocation by Category** - Диаграмма распределения по категориям
    - Crypto
    - Stocks
    - Metals
    - Cash / Stables
    - Speculative

### Блок 3. Главные позиции

- Asset
- Current Value
- Share %
- PnL %
- Status

### Блок 5. Сигналы

- Слишком высокая доля одного актива
- Слишком мало резерва
- Актив вошёл в зону фиксации

# USER PSYCHOLOGY

## Core emotional states

- fear
- greed
- confidence
- uncertainty
- control
- panic
- euphoria

## Product mission

Investor must:
- feel control
- understand risk
- avoid emotional decisions
- see market structure visually
- trust portfolio system

## UI emotional behavior

### Green
Meaning:
- profit
- confidence
- healthy portfolio

### Red
Meaning:
- danger
- overheating
- risk
- emotional warning

### Purple
Meaning:
- strategic mode
- cycle thinking
- long-term positioning

## Dashboard philosophy

The dashboard must not look:
- like exchange terminal
- like Excel
- like admin panel

The dashboard should feel:
- premium
- strategic
- emotional
- cinematic
- intelligent

## Portfolio behavior

Positive pnl:
- subtle glow
- alive feeling
- movement
- energy

Negative pnl:
- tension
- danger
- pressure
- caution

## Risk page purpose

Risk page is:
- emotional stabilizer
- strategic center
- portfolio health monitor

Not:
- analytics spreadsheet

## Fear & Greed role

Fear index is not decoration.

It controls:
- buying aggression
- reserve deployment
- emotional interpretation of market

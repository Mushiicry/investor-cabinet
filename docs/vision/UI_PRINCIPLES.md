# UI PRINCIPLES

## MAIN IDEA

Investor Cabinet
не должен выглядеть как:

- биржевой терминал
- трейдинг панель
- перегруженный dashboard
- набор таблиц
- crypto casino UI

Интерфейс должен создавать ощущение:

- контроля
- спокойствия
- системности
- дисциплины
- дорогого private banking experience
- institutional dashboard
- clean premium analytics

---

# VISUAL FEELING

Главное ощущение UI:

"Я контролирую капитал.
Я понимаю риск.
Я не действую эмоционально."

Даже во время:
- сильной волатильности
- просадки
- страха рынка
- эйфории

UI должен оставаться:
- спокойным
- чистым
- стабильным
- не агрессивным

---

# DESIGN STYLE

Стиль интерфейса:

- dark premium UI
- minimal institutional design
- Apple-like spacing
- clean typography
- large breathing spaces
- soft gradients
- subtle shadows
- smooth borders
- expensive visual feeling

Не использовать:
- кислотные цвета
- перегрузку glow
- gaming style
- Binance style
- Bybit style
- overloaded widgets

---

# COLOR PHILOSOPHY

Основные цвета:

- deep dark blue
- graphite
- soft gold
- muted green
- muted red
- soft white typography

Цвета не должны:
- кричать
- создавать стресс
- вызывать gambling feeling

---

# SPACING RULES

Очень важно:

Investor Cabinet
должен иметь воздух.

Нельзя:
- лепить блоки друг к другу
- делать тесный UI
- перегружать экран

Важно:
- большие padding
- большие border radius
- визуальная иерархия
- ровные grid layouts
- одинаковые отступы

---

# BLOCK PHILOSOPHY

Каждый блок
должен отвечать только на один вопрос.

Например:

Portfolio block:
- что у меня сейчас

Risk block:
- насколько безопасен портфель

Scenario block:
- что делать дальше

Decision block:
- почему удерживается позиция

Нельзя смешивать всё в одном блоке.

---

# TYPOGRAPHY

Использовать:

- clean sans-serif
- большие заголовки
- короткие описания
- минимум текста на экране

Текст:
- легко сканируется глазами
- не перегружает пользователя
- быстро читается

---

# CHARTS

Графики:
- минималистичные
- понятные
- спокойные

Не использовать:
- слишком много линий
- сложные trading indicators
- noisy charts

Charts должны:
- помогать принимать решения
- а не создавать шум

---

# EMOTIONAL UX

Главная задача UX:

уменьшать эмоциональное давление инвестора.

UI должен:
- успокаивать
- структурировать мышление
- возвращать к стратегии
- снижать FOMO
- снижать panic selling

---

# IMPORTANT UI RULES

Нельзя:

- ломать spacing
- уменьшать воздух
- делать интерфейс тесным
- превращать UI в трейдинг терминал
- перегружать dashboard
- делать мелкий текст
- использовать слишком много цветов

Важно сохранять:
- premium feeling
- emotional stability
- clean hierarchy
- institutional style
- readability

---

# LONG TERM VISION

В будущем Investor Cabinet
должен выглядеть как:

- private banking software
- family office dashboard
- institutional portfolio system
- premium capital management platform

А не как:
- crypto exchange
- gambling terminal
- retail trader interface
